## Description
This project demonstrates debugging and fixing common JavaScript errors by creating a working counter application.

## Features
- Increase the counter.
- Decrease the counter.
- Reset the counter to zero.
- Display messages after each action.

## Technologies Used
- HTML
- CSS
- JavaScript

## Bugs and Fixes
- Ensured the counter variable is initialized correctly.
- Used the correct increment and decrement operators.
- Updated the displayed number after every action.
- Connected buttons to the correct JavaScript functions.
- Used textContent to display updated values and messages.

## How to Run
1. Open assignment18.html in a web browser.
2. Click Increase, Decrease, or Reset.
3. Check that the displayed number updates correctly.
